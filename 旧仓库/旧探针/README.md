## 真要重做内存逆向，从哪儿开始

1. 先看 `paoku/tools/re_probe.py`（当前还在用的 frida 探针）和 `paoku/tools/il2cpp_state.js`；
2. 再从这里的 `_rev_scan.py` / `_rev_fields.py` / `_rev_resolve.py` 抄思路，
   候选字段名直接用 `_revy.txt`；
3. 判断「被追击」这种连续量，参考 `_chase_log4.txt` 的观察方式（它记的就是追击对象的实时值）。

确认某条结论已经写进正式代码/文档之后，这里的对应文件就可以删了。
