# 旧仓库 —— 退役的东西都在这儿

**平时不用看这个目录。** 这里放的是以前用过的数据备份、模型、探针脚本和文档 ——
都是**已经退役**的：新流程不会读它们，任何脚本也不会 import 它们。

2026-10-15 做项目结构整理时，把散在 `paoku/runs/`、`paoku/tools/`、`paoku/_归档/` 里的
这些历史包袱统一收进了这里，好让 `paoku/` 只剩"现役"。

> ⚠️ **这个目录整体被 `.gitignore` 排除**（模型几百 MB，不进版本控制）。
> 其中"旧探针"那批文件在 git 里还有一份（它们原本位于 `paoku/tools/`，见下表），
> 但**旧模型、旧数据备份、旧调试产物只在本地磁盘上 —— 删了就真没了**。
